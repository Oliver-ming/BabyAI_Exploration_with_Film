# zez-attention-method：一个主方法及其证据

## 研究范围

选择手册 Track 2 的 Cross-modal fusion。唯一主方法是单帧 ABC：A 语言条件空间热图，B 原视觉特征与热图拼接，C 相对位置偏置的关系注意力。主比较为 BC30 vs ABC。A、AB 是组件/设计消融，FiLM 是替代融合对照。时间记忆及 Residual 平行路线不属于本分支研究问题。

工作假设：与晚期拼接 BC30 相比，ABC 的早期空间融合可以提高未见 S6N3 场景中的闭环成功率；目标选择和导航信息的利用是待诊断的解释。这个假设用于组织现有探索证据，不宣称事先注册或虚构研发时间线。

## 按展示模板组织（9页核心，8分钟陈述 + 2分钟问答）

| 页 | 内容 | 证据与边界 |
|---|---|---|
| 1 | ABC attention fusion 标题与成员 | 一个完整方法 |
| 2 | 任务、观察/动作、主要假设 | S6N3 主指标；一个拥挤示例 |
| 3 | BCNet 基线 | 输入到动作、CE 模仿学习；不能说 MLP 理论上无法组合属性 |
| 4 | 基线复现与 sanity checks | 原始早停基线 + BC30；说明关闭早停的偏离 |
| 5 | 一个完整的 ABC 方法图 | 先讲设计职责；A 生成 M，B 拼接 [H;M] → Conv2，C 网格自注意力 |
| 6 | 受控协议与针对性验证 | 数据/seed/预算/选模/不确定性；三项诊断问题 |
| 7 | 主结果，然后辅助比较 | BC30 vs ABC 在前，A/AB/FiLM 在后；主指标先于迁移 |
| 8 | 成功、失败与局限 | 三个接地相关案例可放备份；正文至少两类失败与短视频 |
| 9 | 回答假设 | 定量结果、不确定性、局限；不引入新方法 |

三项诊断问题：
1. 是否响应指令：固定观察和朝向，替换颜色/类型；动作翻转不是正确性标签。
2. 是否保留导航所需信息：B 在拼接点保留原 H，结合 4501 绕障结果检查实际行为；不能推导后续层永远不丢信息。
3. C 是否提供额外收益：直接对照 AB 与 ABC，结合整体成功率和失败类型。结果可以为负，不预设逐级改善。

特征几何只作为补充。`[H;M]` 与 `M*H` 的整体范数具有不同语义，不能排列成通用质量分数。相对位置偏置不等于整个有限视野、带 flatten 的策略严格平移等变。

## 报告模板映射（正文最多6页）

1. Problem and hypothesis：任务与一个假设。
2. Baseline reproduction：精确基线、软件/硬件/预算、sanity checks、早停差异。
3. Proposed modification：ABC 架构及基线/修改项对照；明确训练权重并未冻结。
4. Experimental protocol：主比较在前、辅助实验在后；披露模型选择与探索使用的测试集，不能宣称未参与设计的新确认集。
5. Results：主表只需 BC30 与 ABC；辅助表再给 A、AB、FiLM。列 S6N3、return、成功长度、val acc、S7N4、数据效率与不确定性。
6. Failure analysis and limitations：分析改善、保留、引入的失败；公开 C 未呈现稳定增益及外推代价。仅3个训练种子，不声称小差值显著。
7. Conclusion：回答同一假设。参考文献、贡献及 AI 使用披露另外保留。

## 不应删掉的证据

- 原始早停基线的复现与 BC30 的来源。
- 三个初始化种子的训练/验证曲线和结果，不能只保留最好种子。
- mission breakdown、至少三个语言接地失败案例，成功与失败视频。
- 次指标与低数据结果；AB/ABC 目前没有50%数据结果，不能用别的架构曲线代替。
- 历史来源与代码版本缺失说明。服务器重跑实际环境必须另行记录。

## 当前交付状态

AB/ABC 的 12 组训练及评估已重跑，权重和成功率复现原结果。主结果为 ABC 97.44% vs 历史 BC30 81.44%（S6）；AB 同为 97.44%，且 S7/S8 高于 ABC，因此不能把 C 写成已验证有效的必要组件。FiLM 的 S6 为 95.89%，优于 BC30 但低于 ABC；宜称替代融合对照，而不是完全失败的方法。关于原因的解释应标为假设，并引用对应诊断证据。

## 0. 一句话结论

1. **在严格的 Concat 融合下，轻量顺序编码器 `gru_small`（32 维 GRU，7,840 语言参数）是唯一在 S6N3 与 S7N4 均 3/3 seed 一致跨越成功门槛的纯编码器改动**：S6N3 闭环 Success 由 `0.814 ± 0.045`（`bc30`/`mean`）提升至 **`0.868 ± 0.013`**（`+0.053`, 3/3），S7N4 跨房间迁移由 `0.697 ± 0.056` 提升至 **`0.803 ± 0.026`**（`+0.107`, 3/3），并 3/3 一致超越等参数非线性词袋对照 `dan`（`0.741`，`+0.062`）与槽位对照 `pos_mlp`（`0.737`，`+0.067`）。
2. **但是，单改语言编码器并不能解决根本的跨模态绑定瓶颈**：`gru_small` 对颜色词的反事实敏感度仅 **`0.0579`**（基线 `0.0507`，即 **94.2%** 的状态下换颜色词不改变动作），表征类失败仍高达 `28.0 / 300`；一旦改为 `FiLM` 融合（`b2_film_nwd`：`0.959` S6N3 / `0.900` S7N4），颜色敏感度跃升至 **`0.2681`**、表征类失败降至 `6.3`。
3. **`FiLM + GRU` 组合无额外叠加收益，反而引入模板词序脆性**：在 GoToLocal 的 5 词定型模板（`go to <art> <color> <type>`）上，无词序的 `FiLM + mean`（`b2_film_nwd`）既更高（`0.959` vs `film_gru_small 0.949` / `film_gru 0.944`）又对任意词置换完全免疫（打乱后跌落 `0.000`）；而 `film_gru` 在颜色/类型词对调（`swap`）下闭环 Success 暴跌 **`-0.342`**（`0.944 → 0.602`）。

## 1. 目标与成功判据

**初始假设**：基线的语言编码器是「14 词表 + 平均词嵌入」，完全丢弃词序；GRU / Transformer 能保留词序，理论上表达能力更强。

**本任务的语言在结构上是退化的**（先验枚举 5,000 条训练/验证 episode 证实）：

```
"go to the red box"    位置: [go] [to] [the] [red] [box]
"go to a blue key"            0    1    2     3     4
```

| 性质 | 实测结论 |
|---|---|
| 是否全部 5 个词 | **是**（5,000 条 episode 词长分布仅 `{5: 5000}`） |
| 前 2 词是否恒定 | **是**（全部以 `go to` 开头） |
| 位置 2 / 3 / 4 | 位置 2 为 `the`/`a`；位置 3 恒为颜色（6 种）；位置 4 恒为类型（3 种），两集合完全不交 |

**成功判据**（预注册）：
- 主对照为 **BC30**（`runs/b3_bc30_seed*`）及 B1 同架构基线 `mean`（`runs/b1_mean_seed*`）。
- 闭环 Success 超越对照 `+0.045`（1 SD）且 **3/3 seed 配对同向**。
- 机制判据：通过同词袋反事实 **词序敏感度探针**（构造性 0 断言自检）、**颜色/类型语义接地探针**、**失败构成拆解** 验证真实因果链。

- 所有模型严格 **跑满 30 epoch，事后选 `val_action_acc` 最优 checkpoint**（对齐支线 3 方法论）。

## 5. 结果分析与前序 B1 审计报告

### 5.1 前序 B1 实验存在的 6 项纰漏与本次修复

1. **`mean_pos` 代数线性对消 bug（设计失效）**：
   旧版 `MeanPoolEncoder(use_pos=True)` 计算 $(\text{emb}(w_t) + \text{pos}(t))$ 的直接均值，中间无任何非线性激活。由于 GoToLocal 指令恒为 `L=5`，任意词序置换下的均值恒等于 $\frac{1}{5}\sum \text{emb}(w_t) + \frac{1}{5}\sum_{t=0}^{4}\text{pos}(t)$——位置编码退化为固定常数偏置，`swap_sensitivity = 0.0000`、`swap_embedding_l1 = 0.00000`。本次新增 `PosMLPEncoder`（`pos_mlp`，`phi` 置于池化前，7,832 参数）修复了该 bug，测得真实非零 `swap_sensitivity = 0.0489`、`swap_embedding_l1 = 0.42143`。
2. **缺少同语言参数量的非线性 BoW / 槽位对照（归因混淆）**：
   旧版仅用扩大 `trunk` 的 `mean_wide`（语言分支仍只有 448 参数线性均值）去对比 7,840 语言参数的 `gru_small`，无法排除「语言支路非线性特征升维」这一混淆因素。本次补全精确对齐参数量的 `dan`（7,855 lang）与 `pos_mlp`（7,832 lang），使 `mean → dan → pos_mlp → gru_small` 形成严谨因果阶梯。
3. **`eval_langenc.py` 与 `probe_word_order.py` 分桶混叠 bug**：
   旧版 `norm_variant` 将 `b3_bc30_seed{0,1,2}` 强行归入 `"mean"`，导致 `b1_langenc_eval.json` 中 `"mean"` 的 `n=6`（混入两批相同权重的副本）、`b1_langenc_s7n4.json` 中直接漏跑了 `b1_mean_seed*`、`b1_word_order_sensitivity.json` 中 `"mean"` 为 `n=4` 且 `n_lang_params: null`，并且全程未计算 3/3 seed 配对检查。本次改为严格 `group_name()` 隔离 `bc30`、`b2_film_nwd` 与 `mean`（全表严格 `n=3`），并输出全量配对统计。
4. **`film_gru` / `film_gru_small` 缺失**：
   原 `LOG.md §2.2 / §3.2` 明确立项的「FiLM + 顺序编码器叠加消融」此前从未实现与训练。本次实现 `FiLMLangBCNet` 并完成 `film_gru_small` 与 `film_gru`（各 3 seed）训练与全套评估。
5. **探针与收尾工程缺失**：
   原 `probe_word_order.py --n-states 400` 虚标（`TEST_SEEDS` 仅 300 项），且缺少闭环词序打乱评估、颜色/类型语义接地反事实探针、失败机制归因、`make_summary.py`、`make_figures.py` 以及 `LOG.md §0 / §4–§7`。现已全部补齐。
6. **112 核服务器 OpenMP 线程未限制**：
   旧版 `eval_langenc.py` 与 `probe_word_order.py` 未设置 `OMP_NUM_THREADS=1` / `torch.set_num_threads(1)` 且串行评估 30+ 模型极慢。现已在各脚本顶层强制单线程 OpenMP/PyTorch 并启用 `ProcessPoolExecutor`（`--workers 12`）。

### 5.2 机制拆解：为什么 `gru_small` 有效，又为什么远不如 FiLM？

- **阶梯归因（S6N3：`0.814 → 0.839 → 0.851 → 0.868`；S7N4：`0.697 → 0.741 → 0.737 → 0.803`）**：
  在 S6N3 同分布上，`gru_small` 的 `+0.053` 净增益中，约一半（`+0.024`）可直接由无序非线性投影 `dan`（0.839）解释，另外加上槽位偏置 `pos_mlp` 可达 `0.851`；但到了 **S7N4 跨房间迁移（更大视野 + 更多干扰物）**，`gru_small` 展现出显著高于 `dan`（`+0.062`, 3/3）和 `pos_mlp`（`+0.067`, 3/3）的结构正则化收益（`0.803` vs `0.741/0.737`）。相反，过宽的 128d `gru`（`66.8k` 语言参数）尽管验证准确率更高（`0.904` vs `0.888`），在 S7N4 却过拟合回落到 `0.747`（不优于宽基线 `mean_wide` `0.749`）。
- **为什么 Concat 下换再好的语言编码器也碰不到 FiLM 的 0.959？**
  反事实探针给出铁证：在 Concat 融合下，`mean`、`dan`、`pos_mlp`、`transformer`、`gru_small` 的**颜色词敏感度全部被锁死在 `0.031–0.058`**——模型 94% 以上情况靠「离目标最近的显眼物体 + 类型形状」作视觉捷径，遇到同型异色干扰物就发生 `attribute_confusion`（14.0–19.3 局/300）。而 `FiLM` 直接通过逐通道仿射调制 `(1+Δγ)·conv1(x)+Δβ` 将语言信号写入视觉空间特征图，把颜色敏感度提升到 `0.2681`，把表征类失败砍掉 **84%**（`38.3 → 6.3`）。
- **退化语法下的"伪词序依赖"警示（Sinha ACL 2021）**：
  因为 GoToLocal 全部 5,000 条指令都是 `go to <art> <color> <type>` 模板，`gru` 与 `film_gru` 学会了把颜色死绑定在索引 3、把类型死绑定在索引 4；当仅调换颜色与类型顺序（`go to the box red`）而**不改变任何词袋语义**时，`b2_film_nwd`（MeanPool）保持 `0.959` 零跌落，而 `film_gru` 惨跌 **`-0.342`**（`0.944 → 0.602`）！注：`film_gru*` 训练默认采用 `wd=0, film_l2=1e-3`，`b2_film_nwd` 采用 `wd=0, film_l2=0`，两者清洁表现均在 ~`0.945–0.959` 的 FiLM 天花板区间内。

## 6. 补充调研（基于实测现象）

1. **DeepSets (Zaheer et al., NeurIPS 2017) 与 `mean_pos` bug**：无非线性的求和池化在位置与词向量相加后满足线性可交换性，$\text{mean}(e_t + p_t) = \text{mean}(e_t) + \text{mean}(p_t)$；只有当元素级变换 $\phi(e_t + p_t)$ 含非线性时，位置编码才真正打破置换不变性（即本文修复后的 `pos_mlp`）。
2. **DAN (Iyyer et al., ACL 2015)**：在固定槽位短指令下，非线性的 Deep Averaging 就能捕获很大一部分表面组合信息（`0.814 → 0.839`），因此评测任何序列编码器时，必须以参数匹配的非线性词袋而非线性词平均作为对照基线。
3. **UnNatural Language Inference (Sinha et al., ACL 2021)**：当数据集缺乏真实组合句法多样性时，RNN/Transformer 会过拟合表面词序位置规律（在 `film_gru` 的 `-0.342` swap 掉点中得到了清晰闭环实证）。

## 7. 结论边界与适用范围

- **严格限定成立范围**：本结论仅适用于不含时序逻辑连接词的单句指令（`GoToLocal`：`go to <art> <color> <type>`），其中词集合即可唯一决定目标语义，且训练集仅有 16.5k 转换。
- **不推广结论**：一旦迁移到包含 `then / after / before / and` 的多子目标任务（如 `PutNextLocal` / `BossLevel`），词袋型编码器（`mean`、`dan`）必然因无法区分前后动作顺序而崩溃，届时必须使用基于序列编码器（如 `gru_small` + FiLM）且辅以多样化语序指令的数据设计。
